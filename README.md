# MirAIe AC controller

**NOTE**: This project was made using AI.

The miraie app doesnt have a web app to control your ac conveniently while on your computer. This project aims to fix that.
<br>
Run server locally in your machine and change ac settings using the web frontend.

### Library used to access miraie auth backend:
Made using [miraie-ac](https://github.com/rkzofficial/miraie-ac) library by rkzofficial that allows the server to talk to the back miraie backend.
